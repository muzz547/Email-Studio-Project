# Leads folder rules

These rules apply to everything in this folder.

- **Everyone in `leads.csv` is made up.** They are practice people for planning and drafting. None of them are real customers.
- **Never add real people or real email addresses.** Not here, not in any other file in this folder.
- **Every row needs a consent value.** Don't add or keep a row with an empty `consent` column. "Consent" means a record of how the person agreed to hear from us, such as `waitlist form`.
- **Never change the `@example.com` addresses.** That domain is reserved and can never receive mail, so no one is ever emailed by mistake. Every new address must end in `@example.com` too.
